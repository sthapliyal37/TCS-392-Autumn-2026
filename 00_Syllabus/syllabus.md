# Course Outcomes (COs)

Upon successful completion of this course, students will be able to:

- **CO1:** Classify security vulnerabilities involved in Internet-based data communication and apply classical cryptographic techniques to mitigate them.
- **CO2:** Apply symmetric block cipher algorithms for secure data transmission and storage.
- **CO3:** Analyze public key cryptographic systems and the role of cryptographic hash functions.
- **CO4:** Understand the mathematical foundations and design principles of public key algorithms for secure communication and message authentication.
- **CO5:** Categorize different types of malware, intrusion techniques, and security mechanisms used to defend computer systems.
- **CO6:** Explain legal and ethical issues related to cybercrime, intellectual property, privacy, and information security.
